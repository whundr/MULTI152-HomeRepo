I have three rooms in this level, two for prefabs, one for combat enemies. The combat room has 6 enemies, 2 large and 4 normal enemies. Each enemy has a canvas built with a Health UI script which gives the slider parameters similar to a health bar. The Health UI communicates with the values given from the Healthconfig script that sends the data to the health UI to adjust what the visual should output. These events are communicated through the Event System which sends the key inputs from the player via script, to various scripts to trigger healing and damage events onto the enemies. When the enemies health value goes to 0 a healthfeedback script is triggered to replace the enemy model with a coin that can be a collectable in the future iteration.
